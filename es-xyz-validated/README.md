# ES XYZ line — jointly validated work (Claude + GPT), October 2026

This folder documents every result of the Erdős–Straus "XYZ" research line that was **validated by more than one party**:
produced by one large language model system (Claude or GPT), checked by the other with independently written code,
and replicated by the research director, Dr William C. Houze, on his own machine (Google Colab). Everything here can be
re-run with standard-library Python 3; nothing needs to be installed. Where a result rests on a published theorem
whose proof was not re-verified inside the project, the label says so.

The Erdős–Straus conjecture — that 4/n = 1/x + 1/y + 1/z has a positive-integer solution for every n ≥ 2 — is **not
proved by anything in this folder**, and nothing here claims to narrow the open case. What is here is a set of exact,
bounded, labelled statements about the problem and about one proposed route to it, together with the evidence.

The Lean 4 certification package (integral matching theorem, B4 descent classification, exact return gates, abstract
forcing theorem, p = 528n+505 family) lives in the root of this repository (commit a92f656, GitHub Actions run #1,
28 Oct 2026) and is not duplicated here.

## Vocabulary

For a prime p ≡ 1 (mod 4) and an integer x with p/4 < x < 3p/4, put d = 4x − p (so d ≡ 3 mod 4). A **channel fires**
at d when some divisor a of x² satisfies a ≡ −x (mod d) (Channel II) or a ≡ −p·x (mod d) (Channel I); either gives an
explicit solution of 4/p (Lemmas 1–2 in the paper). The **channel depth** D(p) is the least firing d. The **energy
route** (GPT, 29 Oct 2026) compares, within a coset cell of the square subgroup of the group generated by the prime
factors of x mod d, the energy E_C = Σ w(r)² of the divisor histogram with the least energy M_C of any "avoiding"
profile of the same mass and symmetries; E_C < M_C forces a solution. **Conjecture Q** asserted such a cell exists for
every p ≡ 1 (mod 24) at some admissible x (a quadratic non-residue mod p).

## How to check the main result yourself

```
cd 03-q-refutation/claude
python3 -I q_attack.py 120000        # ~3 s: prints "Q FAILS at p = 66,361" and "Q-extended: 0 failures"
python3 -I q_attack_1M.py            # ~8–15 min: 25 failures; Q-extended fails at 944,329
cd ../gpt-confirmation && unzip ES_Q_REF_1_Evidence_2026-10-30.zip -d ev
python3 -I claude_validator_of_gpt_certificate.py     # validates GPT's 54 avoiding allocations
```

The program decides Q exactly: it scans every admissible x, skips the x at which no channel fires (there the target bin
is empty and the histogram itself is an avoiding profile, so M ≤ E), and at the few dozen firing x computes every
eligible cell and the exact minimum by the closed formula (GPT's Theorem 5, checked in `02-energy-route-theorems/`).
Sampling is not used anywhere in the decision.

## Result summary (30 Oct 2026)

- **Conjecture Q: REFUTED.** 25 counterexamples among the 9,732 primes p ≡ 1 (mod 24) below 10⁶; the smallest is
  p = 66,361 (16,658 admissible x; 27 firing; 54 eligible cells, all with E ≥ M). All 25 lie in the residual family R
  (square class mod 840, p+1 free of primes ≡ 3 mod 4): 25 of 1,494 R-primes (1.67%). Two independent implementations;
  director replication; GPT's Proposition-15 certificate at 66,361 validated by Claude.
- **Q-extended (any x in (p/4, 3p/4)): REFUTED** at p = 944,329 (65 firing x, 129 eligible cells, none forcing).
- **Erdős–Straus holds at every failing prime**, e.g. 4/66361 = 1/16598 + 1/51363414 + 1/115269057 (GPT; x admissible)
  and 4/944329 = 1/236094 + 1/4772638766 + 1/780326438241 (Claude). The refutation concerns the route, not the conjecture.
- **What survives:** GPT's local theory (exact minimum, collision form, support obstruction, uniform families, complete
  classification of infinite thresholds, scoped finite-menu theorem) is PROVED (paper proofs, cross-checked, director-
  replicated; density corollary CONDITIONAL on a cited sieve bound). The energy test certifies all primes outside R and
  98.3% of R-primes below 10⁶. At the failing primes every firing cell is in the collision-free regime E = M = T.
- **Channel depth:** every p ≡ 1 (mod 24) below 6·10⁷ has D(p) ≤ 107 — a replication of Ionascu–Wilson (2011), who
  report the same bound to ≈ 4.1·10⁹.
